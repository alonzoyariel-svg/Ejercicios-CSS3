# Prácticas de CSS3

Colección de cinco ejercicios que acompañan la práctica académica **“Practicando con CSS3”**. Cada archivo HTML presenta una página independiente para explorar estilos y estructura web.

## Recorrido

- [Ejercicio 2](Ejercicio2.html)
- [Ejercicio 3](Ejercicio3.html)
- [Ejercicio 4](Ejercicio4.html)
- [Ejercicio 5](Ejercicio5.html)

Las imágenes usadas por las páginas están en `IMG/`. Para conservar las rutas de los recursos, mantén los archivos en la estructura original.

## Ejecutar

Clona el repositorio y abre cualquier ejercicio HTML en un navegador moderno. No requiere proceso de compilación.
